### 第2回：SQLite顧客登録システム

`python-practice/lesson02_database/`

PythonとSQLiteを組み合わせた顧客登録プログラムを作成しました。

主な実装内容：

- ニックネーム・生年月日の入力
- UUIDによる顧客IDの自動生成
- SQLiteへの顧客情報の保存
- ニックネーム未入力時のエラー処理
- SELECT文による登録データの取得・表示

※ データベースファイル（`.db`）はGitの管理対象から除外しています。
